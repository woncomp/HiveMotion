# HiveMotion Installer

This folder contains a WiX v5-based installer setup for HiveMotion. The
installer is a **framework-dependent deployment** with a Burn bootstrapper that
automatically installs the .NET 8 Desktop Runtime when it is missing on the
target machine.

## Layout

```
Installer/
├── build-installer.ps1              # One-step build script
├── publish/                         # Framework-dependent publish output
│                                    # (generated by dotnet publish)
├── HiveMotion.Setup/                # WiX MSI project for the application
│   ├── HiveMotion.Setup.wixproj
│   ├── Package.wxs
│   └── HarvestedFiles.wxs           # Generated by build-installer.ps1
├── HiveMotion.Bootstrapper/         # WiX Burn bundle
│   ├── HiveMotion.Bootstrapper.wixproj
│   └── Bundle.wxs
└── artifacts/                       # Final setup.exe and .msi
```

## Prerequisites

Build the installer on Windows.

1. [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later.
2. [WiX Toolset v5](https://wixtoolset.org/docs/intro/):
   ```powershell
   dotnet tool install --global wix
   ```
3. The WiX extensions are referenced as NuGet packages in the `.wixproj` files,
   so they are restored automatically by `dotnet build`.

## Build the installer

From the repository root:

```powershell
.\Installer\build-installer.ps1
```

The script:

1. Publishes the app using `HiveMotion/Properties/PublishProfiles/FrameworkDependent.pubxml`.
2. Generates `HiveMotion.Setup/HarvestedFiles.wxs` from the published files.
3. Builds the WiX MSI (`HiveMotion.Setup`).
4. Builds the WiX bundle (`HiveMotion.Bootstrapper`).
5. Copies the outputs to `Installer/artifacts/`.

`HarvestedFiles.wxs` is overwritten on every build and contains absolute paths
from the local machine. Do not commit the generated version.

## What the installer does

- Detects whether the **.NET 8 Desktop Runtime (x64)** is installed.
- If it is missing, downloads and installs it silently from Microsoft.
- Installs HiveMotion to `C:\Program Files\HiveMotion`.
- Creates a Start Menu shortcut.

## Updating the bundled runtime

The bootstrapper downloads the runtime from Microsoft by default. To ship an
offline installer, download the runtime executable and place it in
`HiveMotion.Bootstrapper/Redist/`:

```powershell
# Example for .NET 8.0.8 x64
Invoke-WebRequest `
  -Uri 'https://download.visualstudio.microsoft.com/download/pr/907765b0-2bf8-494e-93aa-5ef9553c5d68/a9308dc010617e6716c0e6abd53b05ce/windowsdesktop-runtime-8.0.8-win-x64.exe' `
  -OutFile 'Installer\HiveMotion.Bootstrapper\Redist\windowsdesktop-runtime-8.0.8-win-x64.exe'
```

Then edit `Installer/HiveMotion.Bootstrapper/Bundle.wxs` and replace the
`<ExePackagePayload DownloadUrl="..." ... />` element with:

```xml
<ExePackagePayload SourceFile="Redist\windowsdesktop-runtime-8.0.8-win-x64.exe" />
```

Update the `DisplayName`, `Version`, and other attributes as needed.

## Versioning

Before releasing, update the `Version` attributes in both
`HiveMotion.Setup/Package.wxs` and `HiveMotion.Bootstrapper/Bundle.wxs`. Keep
the `UpgradeCode` values unchanged so that Windows Installer can upgrade or
uninstall previous installations correctly.
